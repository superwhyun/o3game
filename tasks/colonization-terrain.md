# 식민지 개척과 정찰 지형 정보

## 목표와 설계
식민선 편성을 미점령 좌표로 출격시키고 정찰 보고서로 행성 규모와 자연 지형을 판단한다. 좌표별 terrain:v1 해시로 환경을 고정하며 기존 점령 행성 데이터는 유지한다. colonize 명령은 목표 ID 없이 좌표를 받으며 식민선과 미점령 상태를 서버에서 검증한다. 도착 시 점령 여부를 재확인하고 고유 좌표 인덱스와 트랜잭션으로 경쟁을 해결한다. 성공 시 식민선 1척을 소비하고 적재 자원을 식민지에 전달한다. 개척 성공 시 나머지 함선은 새 식민지에 주둔하고 편성의 출발지도 새 식민지로 변경하며 임무를 즉시 완료한다. 개척 실패 시에만 귀환한다. 01~03은 최초 귀환 방식 구현 당시의 기록이며 아래 04에서 사용자 정착 규칙을 반영한다. 자연 지형은 정찰 기본 정보이며 점령자의 건설·병력 공개는 기존 첩보 단계 제한을 유지한다.

## 실행 단위

### 01 colonization
- 상태: completed
- 선행: 없음
- 범위: 고정 지형, 출격·도착·귀환 서버, 지도와 임무 UI.
- 완료 조건: 중복 요청 무소비, 동시 개척 단일 점령, 식민선 한 척 소비, 수송 및 생존 함선 정확히 한 번 귀환.
- 검증: 전용 메모리 replica set 통합 테스트, 클라이언트 빌드.
- 결과: 메모리 replica set 동시 개척·중복 출격·귀환 테스트 1 통과, Vite 빌드 통과.

### 02 scouting
- 상태: completed
- 선행: 01
- 범위: 보고서에 지름·온도·전체/사용 가능/불가 면적·테라포밍 예상·생산 특성. 성계 상세와 보고서 기록에 표시.
- 완료 조건: 정찰 환경과 개척 환경 일치, 낮은 첩보 단계에서 건물/병력 유출 없음.
- 검증: 정찰 통합 및 클라이언트 보고서 테스트.
- 결과: 정찰 규칙·클라이언트·HTTP 통합 5 통과, 정찰/개척 환경 일치 메모리 replica set 테스트 통과.

### 03 integration
- 상태: completed
- 선행: 02
- 범위: 전체 회귀, 실제 지도 사용자 경로 확인 및 커밋.
- 완료 조건: 기존 함대·정찰·건설 회귀 통과와 식민지 지도 출격 확인.
- 검증: 서버 테스트, 브라우저 테스트, 프로덕션 빌드.
- 결과: 최종 서버 81 통과/실패 0/스킵 0. 브라우저 연구·건설 5, 정찰 2, 함대 5(실제 개척 드래그 포함) 통과. Vite 빌드 통과(기존 500kB 청크 경고). 실제 사용자의 DB 대신 격리 replica set/브라우저 fixture에서 확인했으며 실제 DB를 초기화하지 않았다.
- 실패와 복구: 최초 전체 브라우저 실행 중 지도 문구 편집으로 Vite HMR이 화면을 재시작해 기존 함대 키보드 테스트가 끊김. 소스 고정 후 함대 5개 재실행 모두 통과.
- 추가 보완: 점령된 좌표 및 식민선 없는 편성 거부, 단독 식민선 사용 후 빈 편성 안내를 손실 대신 개척으로 표시. 최종 서버 전체 재검증 통과.

### 04 colony-settlement (사용자 규칙 수정)
- 상태: completed
- 선행: 03
- 범위: 성공 즉시 정착/임무 완료, 남은 함선과 편성 출발지 이전, 기존 성공 후 귀환 중인 임무 호환. 지도 설명과 브라우저 기대 동작 수정.
- 완료 조건: 개척 성공에 귀환 구간 없음, 신규 식민지에서 편성 재출격 가능, 동시 개척/재정산에 중복 함선 없음, 실패 시 귀환 보존.
- 검증: 메모리 replica set 개척 통합, 전체 서버 회귀, 격리 브라우저 드래그 개척·식민지 선택·교통 회귀, 빌드.
- 결과: 서버 전체 85 통과/실패 0/스킵 0, 브라우저 함대·교통 9 통과, 빌드 통과. 개척 후 즉시 completed/returnTime null, 본거지 함선 0·식민지 잔여 함선 및 편성 이전, 식민지 선택 후 출격 가능 확인. 기존 성공 후 귀환 중 임무는 실제 tick 조회 경로와 직접 처리 동시 실행에도 한 번만 정착함을 추가 검증. 개척 실패는 기존 귀환 유지. 테스트/시간 가속은 격리 DB에서만 수행.
