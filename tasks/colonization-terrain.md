# 식민지 개척과 정찰 지형 정보

## 목표와 설계
식민선 편성을 미점령 좌표로 출격시키고 정찰 보고서로 행성 규모와 자연 지형을 판단한다. 좌표별 terrain:v1 해시로 환경을 고정하며 기존 점령 행성 데이터는 유지한다. colonize 명령은 목표 ID 없이 좌표를 받으며 식민선과 미점령 상태를 서버에서 검증한다. 도착 시 점령 여부를 재확인하고 고유 좌표 인덱스와 트랜잭션으로 경쟁을 해결한다. 성공 시 식민선 1척을 소비하고 적재 자원을 식민지에 전달한다. 나머지 함선은 기존 귀환 경로를 따른다. 자연 지형은 정찰 기본 정보이며 점령자의 건설·병력 공개는 기존 첩보 단계 제한을 유지한다.

## 실행 단위

### 01 colonization
- 상태: completed
- 선행: 없음
- 범위: 고정 지형, 출격·도착·귀환 서버, 지도와 임무 UI.
- 완료 조건: 중복 요청 무소비, 동시 개척 단일 점령, 식민선 한 척 소비, 수송 및 생존 함선 정확히 한 번 귀환.
- 검증: 전용 메모리 replica set 통합 테스트, 클라이언트 빌드.
- 결과: 메모리 replica set 동시 개척·중복 출격·귀환 테스트 1 통과, Vite 빌드 통과.

### 02 scouting
- 상태: completed
- 선행: 01
- 범위: 보고서에 지름·온도·전체/사용 가능/불가 면적·테라포밍 예상·생산 특성. 성계 상세와 보고서 기록에 표시.
- 완료 조건: 정찰 환경과 개척 환경 일치, 낮은 첩보 단계에서 건물/병력 유출 없음.

- 결과: 정찰 규칙·클라이언트·HTTP 통합 5 통과, 정찰/개척 환경 일치 메모리 replica set 테스트 통과.
